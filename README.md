# AcademyNotes

Prototipo de investigación de una plataforma de **seguimiento académico y
evaluación formativa** para colegios. Flask + SQLite + JavaScript vanilla.

> Este proyecto es un prototipo para validación de requisitos y no representa
> todavía la arquitectura definitiva del producto. Los datos son simulados.

El código y la documentación completa están en **[`AcademyNotes/`](AcademyNotes/)**.

```bash
cd AcademyNotes
pip install -r requirements.txt
python app.py     # http://127.0.0.1:5000/  (usuario: admin / demo1234)
```

Guía completa, usuarios de demostración, escenario de demostración y
limitaciones conocidas: [`AcademyNotes/README.md`](AcademyNotes/README.md).
